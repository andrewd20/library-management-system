# 📚 Library Management System

This is a simple console-based **Library Management System** written in Python, developed as an early exercise in object-oriented programming and basic Python functionality (January 2025).

## Features

- **Book Management:** Each book has a title, author, availability status and due date if borrowed.
- **Member Management:** Members are registered then can borrow and return books.
- **Borrowing System:** Books are borrowed for 30 days by default, with automated due date assignment.
- **Search Functionality:** Books can be searched for by title to view their availability.
- **Data Output:** Library information can be retrieved and outputted.

## Concepts Practiced

This project demonstrates foundational Python skills, including:

- **Object-Oriented Programming (OOP):**
  - Use of `class` to represent `Book`, `Member`, and `Library`
  - Encapsulation of data and behaviour within each class
- **Lists & Iteration:** Managing collections of books and members
- **Conditional Logic:** Handling borrowing and returning of books by members
- **datetime Module:** Tracking due dates for borrowed books
- **Use of `len()` Function:** Returning number of available and borrowed books.
- **String Representation (`__str__`):** Outputting human-readable class instances

## How to Run

Requires Python 3.6 or later

Run the script from your terminal using:

```bash
python3 library_management_system.py
```
